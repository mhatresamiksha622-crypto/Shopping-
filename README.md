🛍️ Smart Shopping Cart System

📌 Project Description

Smart Shopping Cart System is a simple shopping application that allows users to add products to a cart, calculate the total bill, apply discounts, and checkout.

🎯 Features

- Add products to cart
- Calculate total bill
- Apply a 10% discount on bills of ₹500 or more
- Display the final bill
- Checkout option
- Reset cart option
- Attractive pink user interface

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GNUSim8051 Assembly Language

📂 Project Files

- "index.html" – Shopping website structure
- "style.css" – Website design and styling
- "script.js" – Shopping cart and billing logic
- "shopping.asm" – Assembly program for calculating the total bill

⚙️ How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser to use the shopping interface.
3. Add products to the cart and check the total bill.
4. Open "shopping.asm" in GNUSim8051 to assemble and execute the assembly program.

🎓 Project Objective

To develop a basic shopping cart and billing system while learning web development and 8051 assembly programming.
